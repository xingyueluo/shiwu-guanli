> 项目：拾光清单——日常事务管理平台（Web 开发技术期末项目 · 单人）
> 工具：DeepSeek Harness 编程助手（对话式 AI 结对开发）
> 说明：本文档按「需求确认 → 关键决策 → 问题排查 → 核心代码问答 → 反思」五段整理，

## 一、需求确认阶段（AI 主动提问，我做选择）

我把课程作业要求（前后端分离、上线部署、创新性/实用性/完整性/真实性四个评分点）
发给 AI 后，它没有直接动手，而是先提出三个问题让我决策：

| 问题 | 给我的选项 | 我的选择 | 理由 |
|---|---|---|---|
| 技术栈 | 原生+Express+SQLite / Vue3+MySQL / 原生+Flask / HTML+SpringBoot | **原生 HTML/CSS/JS + Node/Express + SQLite** | 贴合课程所学，无框架黑盒，答辩能逐行讲清 |
| 功能范围 | 核心任务管理 / 四象限矩阵 / 番茄钟 / 数据可视化（多选） | **核心任务 + 四象限 + 番茄钟**（AI 附赠了统计图表） | 三个模块互相咬合成闭环，工作量饱满又不贪多 |
| 部署环境 | 免费云服务 / 自有服务器 / 局域网演示 | **Render 免费云** | 没有现成服务器，要求网站公网可访问 |

**这一步的收获**：AI 在选项里给出的权衡说明（如"Vue 更现代但学习成本高"）
帮助我理解了选型逻辑，而不是盲目跟风用框架。

## 二、关键技术决策（AI 建议，我追问后确认）

1. **为什么用 `node:sqlite` 而不是 better-sqlite3？**
   AI 解释：better-sqlite3 是 C++ 原生模块，免费云部署时要现场编译经常失败；
   Node 22.5+ 官方内置了 SQLite 驱动，零依赖开箱即用。
   → 我确认：这正好解决"部署上线"这个作业硬要求。

2. **为什么不装 jsonwebtoken / bcrypt？**
   AI 提议全部用 Node 内置 crypto 手写：scrypt 加盐散列存密码、
   HMAC-SHA256 签名做 token。理由是"答辩时好讲解"。
   → 我确认：作业的"真实性"评分点要求我理解每一行，少一个依赖少一个黑盒。

3. **四象限的数据建模**：AI 最初想用单个枚举字段，经讨论改为
   `importance`、`urgency` 两个独立 0/1 字段，象限编号由组合计算。
   好处：以后加"只看重要"这种筛选不用改表结构；拖拽换象限只需 PUT 一个 quadrant 值。

## 三、开发中踩的坑（问题 → 排查 → 解决）

这段最能体现"调试过程是我参与的"，全部真实发生：

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 1 | 工作区文件操作报 `SetNamedSecurityInfoW failed` | Windows 目录权限缺少当前用户的 WRITE_OWNER 项 | 用权限诊断脚本补上完全控制项（有备份可回滚） |
| 2 | `npm install` 报 EPERM 写不进缓存 | 沙箱只允许写工作区，npm 全局缓存在 C 盘 | 加 `--cache <工作区内路径>` 把缓存指进工作区 |
| 3 | 所有 API 返回 404 | `express.Router()` 不接受回调参数，路由根本没挂上 | 改为先 `const r = express.Router()` 再逐个注册 |
| 4 | 启动报 `procesCRET is not defined` | AI 生成代码时把 `process.env.JWT_SECRET` 写坏了（AI 也会犯错，要跑起来才知道） | 修正该行并重启 |
| 5 | 番茄钟按钮显隐逻辑脆弱 | 用 `querySelectorAll('.btn')[0]` 按下标找元素 | 改为按 id 精确控制 |

**教训**：AI 写的代码必须立刻运行验证。第 4 个 bug 说明 AI 自己"以为写对了"
不等于对，冒烟测试（10 组断言）就是为此而写，最终全部通过。

## 四、核心代码问答（我主动问，确保能答辩）

**Q1：番茄钟为什么不用每秒减 1 的倒计时？**
A：浏览器对后台标签页的 setInterval 会节流（最低 1 秒一次甚至更久），逐秒递减会漂移。
正确做法是记录"结束时间戳"，每次刷新显示时用 `endAt - Date.now()` 重算剩余量，
切后台、合盖回来时间都准确。

**Q2：怎么保证用户 A 看不到用户 B 的任务？**
A：每条 SQL 都带 `user_id = ?` 参数条件（prepared statement，同时防注入）；
A 即使猜到 B 的任务 id 去请求，后端查不到行直接返回 404。
冒烟测试第 10 组专门验证了未登录访问返回 401。

**Q3：token 是怎么防伪的？**
A：`header.payload.签名` 结构，签名 = HMAC-SHA256(header.payload, 服务器密钥)。
篡改 payload 里任何字符都会导致签名比对失败；payload 带 exp 过期时间；
密码校验用 timingSafeEqual 防时序攻击。

**Q4：拖拽换象限前后端各做了什么？**
A：前端用 HTML5 Drag & Drop API（dragstart 存任务 id，drop 时读目标格的 quadrant）；
后端只提供一个 `PUT /api/tasks/:id {quadrant}`，内部反推两个布尔字段——
一个接口同时服务表单编辑和拖拽。

**Q5：统计图为什么不用 Chart.js？**
A：作业评分点看重"你学到了什么"。手写 Canvas 需要自己处理坐标换算、
高分屏 devicePixelRatio、渐变和圆角矩形，这些恰好是前端可展示的能力点。
